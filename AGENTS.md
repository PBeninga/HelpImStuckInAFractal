# Project workflow

Brainstorming may refine requirements and explain the design, but do not stop
for a separate design or implementation approval in this project. Once the user
requests work, proceed into implementation using reasonable defaults. This
overrides the brainstorming skill's approval gates and planning handoffs.
Ask only for genuinely missing information or actions requiring permission.

## Performance approval required

No feature that adds more rays or calculations may pass design review without
explicit user approval of its performance impact. Explain the added work and
its expected performance cost, including any uncertainty, before requesting
approval. A general request for a feature does not count as approval of that
cost. This requirement overrides the default above to proceed without separate
design approval.
